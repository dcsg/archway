## What is Archway?

Archway scaffolds services by composing an **architecture** with **capabilities**. Pick your language, pick your structure, pick what your service needs, and Archway wires it all together — config, logging, graceful shutdown, middleware, database connections, and more.

> **Go** is fully supported today. **TypeScript/Node** is next. Archway's provider model makes adding any language straightforward.

<CardGrid>
  <Card title="Pick an Architecture" icon="puzzle">

  </Card>
  <Card title="Add Capabilities" icon="add-document">
    HTTP API, gRPC, MySQL, Redis, JWT auth, rate limiting — add what you need. Each capability is self-contained and composable.
  </Card>

  </Card>

## Quick Example

```bash
# Interactive wizard
archway new my-service

# Or non-interactive
archway new my-service \
  --arch hexagonal \
  --cap platform,bootstrap,http-api,mysql,docker \
  --module github.com/myorg/my-service \
  --no-wizard
```

This gives you a production-ready service with:
- Hexagonal architecture (domain, ports, adapters)
- REST API with Chi router and RFC 7807 errors
- MySQL with connection pooling
- Structured logging and OpenTelemetry
- Bootstrap pattern for testable dependency wiring
- Docker Compose for local development
- `docs/PROJECT.md` with a full anatomy of your project
