# Architecture Decision Records

This directory contains ADRs documenting significant architectural decisions.

## Creating ADRs

Use `/dof:architect` or `/dof:decide` to create new ADRs.

## Format

`NNN-title.md` where NNN is sequential.

## Statuses

- **proposed** — Under discussion
- **accepted** — Decision made, to be implemented
- **deprecated** — No longer applies
- **superseded** — Replaced by another ADR
